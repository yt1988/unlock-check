Häufige Fragen

Wo kann man TVer nutzen?

Nur in diesem Land: Japan. TVer prüft bei jedem Besuch deinen Standort.

Wie erkennt diese Seite, ob TVer geht?

TVer lässt andere Seiten keine seiner Antworten lesen und leitet auch nicht nach Region weiter. Die Seite kann also nur prüfen, ob es über deine Route lädt, und das Land, das andere Dienste erkennen, mit der Liste von TVer vergleichen. Deshalb steht beim Ergebnis „Schätzung“.

TVer zeigt „gesperrt“, aber mein Proxy steht in einem unterstützten Land?

Jeder Dienst ortet IPs mit seiner eigenen Datenbank, und die stimmen nicht immer überein: Derselbe Proxy liegt für den einen in Japan, für den anderen in Hongkong. Manche Dienste weisen außerdem Rechenzentrums-IPs und bekannte VPNs ab. Angezeigt wird das Land, das TVer selbst sieht. Probier einen anderen Server; eine Privatkunden-IP kommt meist leichter durch.

Warum im Browser testen?

Proxy-Apps (Clash, Surge, Shadowrocket und ähnliche) können jede Seite über eine andere Route schicken. Ein Skript auf einem Server testet nur die IP dieses Servers. Diese Seite besucht jeden Dienst aus deinem Browser, über die Route, die du wirklich nutzt.

Was bedeuten Offizielle API, Offizieller Standort, Weiterleitungstest und Schätzung?

Sie zeigen, wie verlässlich ein Ergebnis ist, das verlässlichste zuerst. Offizielle API: Die Regions-API des Dienstes sagt selbst, ob er geht. Offizieller Standort: Die Server des Dienstes nennen das Land, das sie erkennen, abgeglichen mit den unterstützten Ländern. Weiterleitungstest: ob der Dienst dich auf seine Seite „nicht verfügbar“ geschickt hat. Schätzung: Der Dienst lässt nichts lesen, daher ist nur bekannt, dass er lädt, und es zählt das Land, das andere Dienste erkennen.

Warum erkennen die Dienste unterschiedliche Länder?

Deine Proxy-Regeln schicken sie vielleicht über verschiedene Server (Split-Routing), oder die Dienste nutzen unterschiedliche IP-Datenbanken. Dann zeigt die Seite, welche Dienste welches Land sehen. Damit sie übereinstimmen, schick diese Dienste über denselben Server.

Warum spielt die Zeitzone eine Rolle?

KI-Dienste vergleichen die Zeitzone deines Browsers mit dem Land deiner IP. Eine deutsche Zeitzone mit einer IP in den USA sieht nach Proxy aus und kann zusätzliche Prüfungen auslösen. Es hilft, die Zeitzone des Geräts an deine IP anzupassen.

Werden meine Daten hochgeladen?

Deine Ergebnisse nicht. Dein Browser fragt jeden Dienst direkt, und die Ergebnisse bleiben in deinem Browser. Zwei Dinge erreichen während eines Tests unseren eigenen Server in Tokio: die stündliche Statusdatei, die von data.1ms.dog gelesen wird, und die Auflösung eines Einmal-Namens unter l.1ms.dog, die zeigt, über welchen DNS-Resolver deine Anfragen laufen. Unser Nameserver sieht die IP dieses Resolvers und, wenn der Resolver es weitergibt, das /24 deines Netzes (EDNS Client Subnet); er behält beides 2 Minuten, damit die Seite es lesen kann, vergisst es dann und schreibt keine Logs. Die Seite zeigt es nur dir; in einen geteilten Link kommt es nie. Wenn du auf 1ms.dog teilst, werden der Kurzlink und sein Vorschaubild dort gespeichert, damit Chat-Apps sie anzeigen; geteilte Ergebnisse enthalten keine IPs. Nutze „IPs ausblenden“ vor einem Screenshot.
