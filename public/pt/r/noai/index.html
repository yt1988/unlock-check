Perguntas

Por que verificar pelo navegador?

Proxies com regras (Clash, Surge, Shadowrocket, sing-box…) escolhem uma rota por site. Um script em um servidor só vê o IP do servidor; esta página consulta cada serviço pelo seu navegador, então cada requisição vai pela rota que suas regras dão a ela.

O que significam API própria, Servidor próprio, Redirecionamentos e Deduzido?

O quanto um veredito é seguro, do mais forte ao mais fraco. API própria: a API de região do serviço respondeu. Servidor próprio: o servidor Cloudflare do serviço diz em que país vê você, comparado com a lista publicada. Redirecionamentos: a página contou para onde o serviço mandou você. Deduzido: o serviço não pode ser lido; ele está acessível e o país é o que a maioria dos serviços vê.

Por que nem todos os serviços veem o mesmo país?

Suas regras podem mandá-los por proxies diferentes, e cada serviço localiza IPs com seu próprio banco de dados. Quando os países diferem, a página mostra quais serviços veem qual.

Por que o fuso horário importa?

Serviços de IA comparam o fuso horário do navegador com o país do IP. Um navegador em America/Sao_Paulo com IP dos EUA é um sinal típico de proxy e pode trazer verificações mais rígidas.

Algo é enviado a este site?

Não. Seu navegador consulta cada serviço diretamente; este site só serve arquivos estáticos e nunca vê seus resultados. Oculte os IPs antes de uma captura de tela.
