Perguntas

Onde dá para usar Telegram?

Em quase todo lugar, exceto: China, Coreia do Norte, Irã.

Como esta página sabe se Telegram funciona?

Telegram não deixa outros sites lerem nenhuma resposta dele e não redireciona por região. Então a página só pode verificar se ele abre pela sua rota, e compara o país em que os outros serviços localizam você com a lista de Telegram. O resultado é marcado como "Estimativa".

Telegram diz bloqueado, mas meu proxy está em um país suportado?

Cada serviço localiza IPs com o próprio banco de dados, e eles nem sempre concordam: o mesmo proxy pode estar no Japão para um e em Hong Kong para outro. Alguns serviços também recusam IPs de data center e VPNs conhecidas. O país mostrado é o que Telegram vê.

Por que verificar no navegador?

Apps de proxy (Clash, Surge, Shadowrocket e parecidos) mandam cada site por uma rota diferente. Um script em um servidor só testa o IP desse servidor. Esta página visita cada serviço pelo seu navegador, pela rota que você usa normalmente.

O que significam API oficial, Localização dele, Teste de redirecionamento e Estimativa?

O quanto um resultado é confiável, do mais ao menos confiável. API oficial: a API de região do serviço diz se funciona. Localização dele: os servidores do serviço dizem em que país localizam você, comparado com os países que ele publica. Teste de redirecionamento: se o serviço mandou você para a página de "indisponível". Estimativa: o serviço não deixa ler nada; só se sabe que abre, e o país vem dos outros serviços.

Por que os serviços me localizam em países diferentes?

Suas regras de proxy podem mandá-los por servidores diferentes, ou os serviços usam bancos de dados de IP diferentes. Nesse caso, a página mostra quais serviços veem qual país.

Por que o fuso horário importa?

Serviços de IA comparam o fuso horário do navegador com o país do seu IP. Um fuso horário do Brasil com IP dos EUA parece proxy e pode gerar verificações mais rígidas.

Meus dados são enviados?

Não. Seu navegador visita cada serviço diretamente; este site só entrega a página e nunca vê seus resultados. Use "Ocultar IPs" antes de uma captura de tela.
