Perguntas frequentes

Onde dá para usar TVB Anywhere+?

TVB Anywhere+ não publica onde está disponível, então a página mostra só o país que ele detecta.

Como esta página sabe se TVB Anywhere+ funciona?

TVB Anywhere+ tem uma API de região pública (o próprio site dele usa) que outras páginas podem ler. Seu navegador pergunta direto a ela, pela sua rota, e ela responde se você pode usar TVB Anywhere+ e em que país você está. Os scripts de teste de desbloqueio de linha de comando usam a mesma API.

TVB Anywhere+ aparece como bloqueado, mas meu proxy está num país suportado. Por quê?

Cada serviço localiza IPs com o próprio banco de dados, e eles nem sempre concordam: o mesmo proxy pode estar no Japão para um e em Hong Kong para outro. Alguns serviços também recusam IPs de data center e VPNs conhecidas. O país mostrado é o que o próprio TVB Anywhere+ vê. Tente outro servidor; um IP residencial costuma passar com mais facilidade.

Por que testar no navegador?

Apps de proxy (Clash, Surge, Shadowrocket e outros) podem mandar cada site por uma rota diferente. Um script num servidor só testa o IP daquele servidor. Esta página acessa cada serviço a partir do seu navegador, pela rota que você realmente usa.

O que significam API oficial, Localização oficial, Teste de redirecionamento e Estimativa?

Mostram o quanto o resultado é confiável, do mais para o menos confiável. API oficial: a API de região do próprio serviço diz se funciona. Localização oficial: os servidores do serviço dizem qual país detectam, comparado com os países suportados. Teste de redirecionamento: se o serviço mandou você para a página de "indisponível". Estimativa: o serviço não deixa ler nada, então só se sabe que abre, e vale o país que os outros serviços detectam.

Por que os serviços detectam países diferentes?

As regras do seu proxy podem mandar cada um por um servidor diferente (roteamento dividido), ou os serviços usam bancos de dados de IP diferentes. Quando isso acontece, a página mostra quais serviços veem qual país. Para que concordem, mande esses serviços pelo mesmo servidor.

Por que o fuso horário importa?

Serviços de IA comparam o fuso horário do navegador com o país do seu IP. Um fuso do Brasil com um IP nos Estados Unidos parece proxy e pode gerar verificações extras. Ajustar o fuso do aparelho para o do seu IP ajuda.

Meus dados são enviados?

Não durante o teste. Seu navegador acessa cada serviço diretamente; este site só entrega a página e nunca vê seus resultados. Se você compartilhar no 1ms.dog, o link curto e a imagem de prévia ficam salvos lá para que os apps de mensagem possam exibi-los; resultados compartilhados não incluem IPs. Use "Ocultar IPs" antes de tirar um print.
