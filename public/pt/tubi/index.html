Perguntas frequentes

Onde dá para usar Tubi?

Tubi não publica onde está disponível, então a página mostra só o país que ele detecta.

Como esta página sabe se Tubi funciona?

A resposta de Tubi não pode ser lida, mas dá para saber se ele redireciona você. Um navegador segue no máximo 20 redirecionamentos, então a página primeiro passa a requisição por um número fixo de redirecionamentos neste site e depois manda para Tubi. Se ainda abrir, Tubi não redirecionou. Se falhar, Tubi redirecionou você: é assim que ele manda visitantes de regiões não suportadas para a página de "indisponível".

Tubi aparece como bloqueado, mas meu proxy está num país suportado. Por quê?

Cada serviço localiza IPs com o próprio banco de dados, e eles nem sempre concordam: o mesmo proxy pode estar no Japão para um e em Hong Kong para outro. Alguns serviços também recusam IPs de data center e VPNs conhecidas. O país mostrado é o que o próprio Tubi vê. Tente outro servidor; um IP residencial costuma passar com mais facilidade.

Por que testar no navegador?

Apps de proxy (Clash, Surge, Shadowrocket e outros) podem mandar cada site por uma rota diferente. Um script num servidor só testa o IP daquele servidor. Esta página acessa cada serviço a partir do seu navegador, pela rota que você realmente usa.

O que significam API oficial, Localização oficial, Teste de redirecionamento e Estimativa?

Mostram o quanto o resultado é confiável, do mais para o menos confiável. API oficial: a API de região do próprio serviço diz se funciona. Localização oficial: os servidores do serviço dizem qual país detectam, comparado com os países suportados. Teste de redirecionamento: se o serviço mandou você para a página de "indisponível". Estimativa: o serviço não deixa ler nada, então só se sabe que abre, e vale o país que os outros serviços detectam.

Por que os serviços detectam países diferentes?

As regras do seu proxy podem mandar cada um por um servidor diferente (roteamento dividido), ou os serviços usam bancos de dados de IP diferentes. Quando isso acontece, a página mostra quais serviços veem qual país. Para que concordem, mande esses serviços pelo mesmo servidor.

Por que o fuso horário importa?

Serviços de IA comparam o fuso horário do navegador com o país do seu IP. Um fuso do Brasil com um IP nos Estados Unidos parece proxy e pode gerar verificações extras. Ajustar o fuso do aparelho para o do seu IP ajuda.

Meus dados são enviados?

Seus resultados, não. Seu navegador consulta cada serviço diretamente, e os resultados ficam no seu navegador. Durante um teste, duas coisas chegam ao nosso próprio servidor em Tóquio: o arquivo de status horário lido de data.1ms.dog, e a consulta de um nome descartável sob l.1ms.dog, que mostra por qual resolvedor DNS passam suas consultas. Nosso servidor de nomes vê o IP desse resolvedor e, se o resolvedor repassar, o /24 da sua rede (EDNS Client Subnet); guarda isso por 2 minutos para a página ler de volta, depois descarta, e não grava logs. A página mostra só para você; nunca vai num link compartilhado. Ao compartilhar no 1ms.dog, o link curto e a imagem de prévia ficam guardados lá para os apps de chat exibirem; resultados compartilhados não incluem IPs. Use Ocultar IPs antes de fazer uma captura de tela.
