這個頁面怎麼判斷 Claude 能不能用？

Claude 使用 Cloudflare，它網域下的 /cdn-cgi/trace 會回傳這次造訪來自哪個國家，並且允許其他網頁讀取。這就是 Claude 自己看到的位置，再拿它對照 Claude 公布的可用地區。

Claude 顯示不可用，但我的代理明明在支援的地區？

各服務用自己的 IP 資料庫定位，結果不一定一樣：同一個代理，有的服務認為在日本，有的認為在香港。另外，有些服務會拒絕機房 IP 和已知的 VPN。頁面顯示的就是 Claude 自己看到的位置。

為什麼要在瀏覽器裡測？

代理軟體（Clash、Surge、Shadowrocket 等）會依規則讓不同網站走不同線路。在伺服器上執行的檢測腳本只能測那台伺服器的 IP。這個頁面在你的瀏覽器裡直接造訪每個服務，走的就是你平常開啟它們的線路。

「官方介面」「官方定位」「跳轉判斷」「推測」有什麼差別？

代表結論有多可靠，從高到低。官方介面：服務自己的地區介面直接說能不能用。官方定位：服務的伺服器告訴我們你被定位在哪個國家，再對照它公布的可用地區。跳轉判斷：看服務有沒有把你轉到「本地區無法使用」頁面。推測：服務不讓讀取任何結果，只確認能開啟，國家依其他服務的定位來算。

為什麼不同服務把我定位在不同國家？

可能是你的代理規則讓它們走了不同節點，也可能是各服務用的 IP 資料庫不一樣。出現這種情況時，頁面會列出每個國家對應哪些服務。

為什麼要看時區？

AI 服務會比對瀏覽器時區和 IP 所在國家。例如時區在台灣、IP 卻在美國，就很像在用代理，可能觸發更嚴格的驗證。

會上傳我的資料嗎？

不會。瀏覽器直接造訪各個服務，本站只提供網頁檔案，看不到你的結果。截圖前可以點「隱藏 IP」。
