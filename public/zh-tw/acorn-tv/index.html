常見問題

Acorn TV 在哪些國家和地區可以用？

依 Acorn TV 官方公布的名單，共 6 個國家和地區：加拿大、西班牙、波多黎各、美國、紐西蘭、澳洲。 來源

這個頁面怎麼判斷 Acorn TV 能不能用？

Acorn TV 不讓其他網站讀取它的任何回應，也不會依地區轉址。頁面只能確認它在你的路徑上開得了，再用其他服務認為你在的國家對照 Acorn TV 的支援地區，所以結果標為「推測」。

Acorn TV 顯示不可用，可是我的代理明明在支援的地區？

每個服務用自己的 IP 資料庫判斷位置，結果不一定相同：同一個代理，有的認為在日本，有的認為在香港。另外，有些服務會直接拒絕機房 IP 和已知的 VPN。這裡顯示的就是 Acorn TV 自己看到的位置。可以換個節點試試，家用寬頻 IP 通常比較容易通過。

為什麼要在瀏覽器裡測？

代理軟體（Clash、Surge、Shadowrocket 等）會依規則讓不同網站走不同路徑。在伺服器上執行的檢測腳本，只能測那台伺服器的 IP。這個頁面在你的瀏覽器裡直接連到每個服務，走的就是你平常開啟它們的路徑。

「官方 API」「官方定位」「轉址判斷」「推測」有什麼不同？

代表結果有多可靠，由高到低。官方 API：服務自己的地區 API 直接說能不能用。官方定位：服務的伺服器告訴我們它認為你在哪個國家，再對照它公布的支援地區。轉址判斷：看服務有沒有把你轉到「無法使用」頁面。推測：服務什麼都不讓讀，只能確認開得了，國家依其他服務的判斷來算。

為什麼不同服務認為我在不同國家？

可能是代理規則讓它們走了不同節點（也就是分流），也可能是各服務用的 IP 資料庫不一樣。遇到這種情況，頁面會列出每個國家對應哪些服務。想讓它們一致，可以把這些服務設定成走同一個節點。

為什麼要看時區？

AI 服務會比對瀏覽器時區和 IP 所在的國家。例如時區在中國台灣、IP 卻在美國，看起來就像在用代理，可能觸發更嚴格的驗證。把裝置時區改成和 IP 一致，可以減少這種情況。

會上傳我的資料嗎？

檢測結果不會上傳。瀏覽器直接詢問每個服務，結論只留在你的瀏覽器裡。檢測時有兩樣東西會到我們自己在東京的伺服器：一是從 data.1ms.dog 讀取每小時巡檢的狀態檔；二是查詢 l.1ms.dog 下一個一次性的網域名稱，用來看你的 DNS 查詢走的是哪個解析器。我們的 DNS 伺服器能看到這個解析器的 IP，如果解析器轉送了，還能看到你所在網段的 /24（EDNS Client Subnet）。這些只保留 2 分鐘供頁面讀回，之後丟棄，不寫日誌；頁面只顯示給你自己看，分享連結裡不會有。在 1ms.dog 分享時，短連結和預覽圖會存在那裡，方便聊天軟體顯示；分享的結果不帶 IP。截圖前可以先點「隱藏 IP」。
