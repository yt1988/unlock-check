Questions fréquentes

Pourquoi tester dans le navigateur ?

Les applis de proxy (Clash, Surge, Shadowrocket, etc.) peuvent envoyer chaque site par un chemin différent. Un script sur un serveur ne teste que l'IP de ce serveur. Cette page visite chaque service depuis votre navigateur, par le chemin que vous utilisez vraiment.

Que veulent dire API officielle, Localisation officielle, Test de redirection et Estimation ?

Ils indiquent la fiabilité du résultat, du plus fiable au moins fiable. API officielle : l'API de région du service dit lui-même s'il marche. Localisation officielle : les serveurs du service indiquent le pays qu'ils détectent, comparé aux pays qu'il prend en charge. Test de redirection : le service vous a-t-il renvoyé vers sa page « non disponible » ? Estimation : le service ne laisse rien lire, donc on sait seulement qu'il s'ouvre, et on prend le pays détecté par les autres services.

Pourquoi les services détectent-ils des pays différents ?

Les règles de votre proxy les font peut-être passer par des serveurs différents (routage séparé), ou les services utilisent des bases de données d'IP différentes. Dans ce cas, la page indique quels services voient quel pays. Pour les mettre d'accord, faites passer ces services par le même serveur.

Pourquoi le fuseau horaire compte-t-il ?

Les services d'IA comparent le fuseau horaire de votre navigateur au pays de votre IP. Un fuseau en France avec une IP aux États-Unis ressemble à un proxy et peut déclencher des vérifications supplémentaires. Régler le fuseau de l'appareil sur celui de votre IP aide.

Mes données sont-elles envoyées ?

Vos résultats, non. Votre navigateur interroge chaque service directement et les résultats restent dans votre navigateur. Pendant un test, deux choses arrivent à notre propre serveur à Tokyo : le fichier d’état horaire lu sur data.1ms.dog, et la résolution d’un nom à usage unique sous l.1ms.dog, qui montre par quel résolveur DNS passent vos requêtes. Notre serveur de noms voit l’IP de ce résolveur et, si le résolveur la transmet, le /24 de votre réseau (EDNS Client Subnet) ; il les garde 2 minutes pour que la page les relise, puis les oublie, et n’écrit aucun journal. La page ne les montre qu’à vous ; ils ne vont jamais dans un lien partagé. Quand vous partagez sur 1ms.dog, le lien court et son image d’aperçu y sont stockés pour que les messageries les affichent ; les résultats partagés n’incluent pas d’IP. Utilisez Masquer les IP avant une capture d’écran.
