常见问题

Twitch 在哪些国家和地区能用？

除了以下地方，基本都能用：中国。

这个页面怎么判断 Twitch 能不能用？

Twitch 不让其他网站读取它的任何回答，也不按地区跳转。页面只能确认它在你的线路上打得开，再拿其他服务认为你在的国家去对照 Twitch 的支持地区，所以结果标为「推测」。

Twitch 显示不可用，可我的代理明明在支持的地区？

每个服务用自己的 IP 数据库判断位置，结果不一定一样：同一个代理，有的认为在日本，有的认为在香港。另外，有些服务会直接拒绝机房 IP 和已知的 VPN。这里显示的，就是 Twitch 自己看到的位置。可以换个节点试试，家宽 IP 一般更容易通过。

为什么要在浏览器里测？

代理软件（Clash、Surge、Shadowrocket 等）会按规则让不同网站走不同线路。放在服务器上跑的检测脚本，只能测那台服务器的 IP。这个页面在你的浏览器里直接访问每个服务，走的就是你平时打开它们的那条线路。

「官方接口」「官方定位」「跳转判断」「推测」是什么意思？

表示结论有多可靠，从高到低。官方接口：服务自己的地区接口直接说能不能用。官方定位：服务的服务器告诉我们它认为你在哪个国家，再对照它公布的支持地区。跳转判断：看服务有没有把你转到「本地区不可用」页面。推测：服务什么都不让读，只能确认打得开，国家按其他服务的判断来算。

为什么不同服务认为我在不同国家？

可能是代理规则让它们走了不同节点（也就是分流），也可能是各家用的 IP 数据库不一样。出现这种情况时，页面会列出每个国家对应哪些服务。想让它们一致，可以把这些服务分到同一个节点。

为什么要看时区？

AI 服务会对比浏览器时区和 IP 所在的国家。比如时区是中国、IP 却在美国，看起来就像在用代理，可能触发更严格的验证。把电脑的时区改成和 IP 一致，能减少这种情况。

会上传我的数据吗？

检测时不会：你的浏览器直接访问各个服务，本站只提供网页，看不到你的结果。在 1ms.dog 上点「分享」时，短链接和预览图会保存在 1ms.dog，聊天软件里才能显示；分享的结果不含 IP。截图前可以先点「隐藏 IP」。
