Preguntas

¿Dónde se puede usar FOD?

Solo en Japón. FOD comprueba tu ubicación en cada visita.

¿Cómo sabe esta página si FOD funciona?

FOD tiene una API de región pública (la usa su propio sitio) que otras páginas pueden leer. Tu navegador la consulta directamente, por tu ruta, y responde si puedes usar FOD y en qué país estás. Los scripts de desbloqueo de línea de comandos usan la misma API.

FOD dice bloqueado, pero mi proxy está en un país admitido.

Cada servicio ubica las IP con su propia base de datos y no siempre coinciden: el mismo proxy puede estar en Japón para uno y en Hong Kong para otro. Algunos servicios también rechazan IP de centros de datos y VPN conocidas. El país que se muestra es el que ve FOD.

¿Por qué comprobar en el navegador?

Las apps de proxy (Clash, Surge, Shadowrocket y similares) envían cada sitio por una ruta distinta. Un script en un servidor solo comprueba la IP de ese servidor. Esta página visita cada servicio desde tu navegador, por la ruta que usas normalmente.

¿Qué significan API oficial, Su ubicación, Por redirección y Estimado?

Lo fiable que es un resultado, de más a menos. API oficial: la API de región del propio servicio dice si funciona. Su ubicación: los servidores del servicio dicen en qué país te sitúan, comparado con los países que publica. Por redirección: si el servicio te envió a su página de «no disponible». Estimado: el servicio no deja leer nada; solo se sabe que abre, y se usa el país en que te sitúan los demás.

¿Por qué los servicios me sitúan en países distintos?

Tus reglas de proxy pueden enviarlos por servidores distintos, o los servicios usan bases de datos de IP distintas. Cuando pasa, la página indica qué servicios ven cada país.

¿Por qué importa la zona horaria?

Los servicios de IA comparan la zona horaria del navegador con el país de tu IP. Una zona horaria de España con una IP de EE. UU. parece un proxy y puede activar comprobaciones más estrictas.

¿Se suben mis datos?

No. Tu navegador visita cada servicio directamente; este sitio solo sirve la página y nunca ve tus resultados. Usa «Ocultar IP» antes de una captura.
