Preguntas

¿Dónde está disponible Disney+?

Disney+ no publica una lista de países; la página muestra el país en que te ve.

¿Cómo comprueba esta página Disney+?

La respuesta de Disney+ no se puede leer, pero sí contar a dónde te envía: un navegador sigue como máximo 20 redirecciones, así que la petición pasa antes por un número conocido de redirecciones de este sitio. Si aun así carga, Disney+ no añadió ninguna; si falla, te redirigió, que es como envía a los visitantes a su página de «no disponible».

Disney+ dice no disponible, pero mi proxy está en un país admitido.

Cada servicio ubica tu IP con su propia base de datos y no siempre coinciden: un proxy puede estar en Japón para uno y en Hong Kong para otro. Algunos servicios también rechazan direcciones de centros de datos y VPN conocidas. El país que se muestra es el que ve Disney+.

¿Por qué comprobar desde el navegador?

Los proxies con reglas (Clash, Surge, Shadowrocket, sing-box…) eligen una ruta por sitio web. Un script en un servidor solo ve la IP del servidor; esta página consulta cada servicio desde tu navegador, así que cada petición va por la ruta que le dan tus reglas.

¿Qué significan API propia, Servidor propio, Redirecciones y Deducido?

Lo seguro que es un veredicto, de más a menos. API propia: respondió la API de región del servicio. Servidor propio: el servidor de Cloudflare del propio servicio dice en qué país te ve, comparado con su lista publicada. Redirecciones: la página contó a dónde te envió el servicio. Deducido: el servicio no se puede leer en absoluto; es accesible y el país es el que ven la mayoría de los servicios.

¿Por qué no todos los servicios ven el mismo país?

Tus reglas pueden enviarlos por proxies distintos, y cada servicio ubica las IP con su propia base de datos. Cuando los países difieren, la página indica qué servicios ven cada uno.

¿Por qué importa la zona horaria?

Los servicios de IA comparan la zona horaria del navegador con el país de la IP. Un navegador en Europe/Madrid con una IP de EE. UU. es una señal típica de proxy y puede traer comprobaciones más estrictas.

¿Se envía algo a este sitio?

No. Tu navegador consulta cada servicio directamente; este sitio solo sirve archivos estáticos y nunca ve tus resultados. Oculta las IP antes de una captura.
