Preguntas frecuentes

¿Dónde se puede usar DMM TV?

Solo en Japón. DMM TV comprueba dónde estás en cada visita.

¿Cómo sabe esta página si DMM TV funciona?

DMM TV tiene una API de región pública (su propia web la usa) que otras páginas pueden leer. Tu navegador le pregunta directamente, por tu ruta, y ella responde si puedes usar DMM TV y en qué país estás. Los scripts de desbloqueo de línea de comandos usan la misma API.

DMM TV aparece como bloqueado, pero mi proxy está en un país admitido. ¿Por qué?

Cada servicio ubica las IP con su propia base de datos, y no siempre coinciden: el mismo proxy puede estar en Japón para uno y en Hong Kong para otro. Algunos servicios también rechazan las IP de centro de datos y las VPN conocidas. El país que se muestra es el que ve el propio DMM TV. Prueba otro servidor; una IP residencial suele pasar con más facilidad.

¿Por qué se prueba desde el navegador?

Las apps de proxy (Clash, Surge, Shadowrocket y similares) pueden enviar cada sitio por una ruta distinta. Un script en un servidor solo prueba la IP de ese servidor. Esta página visita cada servicio desde tu navegador, por la ruta que realmente usas.

¿Qué significan API oficial, Ubicación oficial, Prueba de redirección y Estimación?

Indican qué tan fiable es el resultado, de más a menos. API oficial: la API de región del propio servicio dice si funciona. Ubicación oficial: los servidores del servicio dicen en qué país te ubican, y se compara con los países que admite. Prueba de redirección: si el servicio te envió a su página de «no disponible». Estimación: el servicio no deja leer nada, así que solo se sabe que abre y se usa el país que ven otros servicios.

¿Por qué los servicios me ubican en países distintos?

Puede que las reglas de tu proxy los envíen por servidores distintos (enrutamiento dividido), o que los servicios usen bases de datos de IP diferentes. Cuando pasa, la página muestra qué servicios ven cada país. Para que coincidan, envía estos servicios por el mismo servidor.

¿Por qué importa la zona horaria?

Los servicios de IA comparan la zona horaria de tu navegador con el país de tu IP. Una zona horaria de México con una IP de Estados Unidos parece un proxy y puede activar verificaciones adicionales. Poner la zona horaria del dispositivo acorde con tu IP ayuda.

¿Se suben mis datos?

No mientras se hace la prueba. Tu navegador contacta cada servicio directamente; este sitio solo entrega la página y nunca ve tus resultados. Si compartes en 1ms.dog, el enlace corto y su imagen de vista previa se guardan allí para que las apps de chat puedan mostrarlos; los resultados compartidos no incluyen IP. Usa Ocultar IP antes de hacer una captura.
