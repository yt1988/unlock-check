よくある質問

なぜブラウザから確認する？

ルールベースのプロキシ（Clash、Surge、Shadowrocket、sing-box など）はサイトごとに経路を選びます。サーバー上のスクリプトはサーバー自身の IP しか見られませんが、このページはあなたのブラウザから各サービスに問い合わせるので、どのリクエストもあなたのルールが決めた経路を通ります。

「公式 API」「自社サーバー」「リダイレクト」「推定」とは？

判定の確かさで、強い順です。公式 API：サービス自身の地域判定 API が答えた。自社サーバー：サービス自身の Cloudflare 拠点が見ている国を、公開リストと照合した。リダイレクト：サービスがどこへ転送したかを数えた。推定：応答はまったく読めず、接続できることだけを確認し、国はほかのサービスの多くが見ている国を使った。

サービスごとに国が違うのはなぜ？

ルールで別々のプロキシを通っているかもしれませんし、各サービスは独自のデータベースで IP の位置を決めています。国が違うときは、どのサービスがどの国を見ているかを表示します。

タイムゾーンはなぜ関係する？

AI サービスはブラウザのタイムゾーンと IP の国を比べます。ブラウザが Asia/Tokyo なのに IP が米国なら典型的なプロキシの特徴で、確認が厳しくなることがあります。

このサイトに何か送られる？

いいえ。ブラウザが各サービスに直接問い合わせます。このサイトは静的ファイルを配信するだけで、結果は見えません。スクリーンショットの前に IP を隠せます。

結果を共有

画像とリンクはブラウザ内で作られ、各サービスの結果と国だけを含み、IP は含みません。
