よくある質問

FOD はどの国や地域で使えますか？

日本でのみ使えます。FOD はアクセスのたびに場所を確認します。

このページは FOD が使えるかどうかをどう判断していますか？

FOD には公開された地域 API があり（FOD 自身のサイトも使っています）、ほかのページからも読み取れます。ブラウザがふだんの経路でこの API に直接問い合わせ、使えるかどうかと判定された国を受け取ります。コマンドラインの判定スクリプトも同じ API を使っています。

FOD が利用不可と出ますが、プロキシは対応国にあるはずでは？

サービスごとに独自の IP データベースで場所を判定するため、結果が一致するとは限りません。同じプロキシでも、日本と判定するサービスもあれば、香港と判定するサービスもあります。また、データセンターの IP や既知の VPN を拒否するサービスもあります。表示されている国は FOD 自身が判定したものです。別のサーバーを試してください。家庭用回線の IP のほうが通りやすい傾向があります。

なぜブラウザで確認するのですか？

プロキシアプリ（Clash、Surge、Shadowrocket など）は、ルールに従ってサイトごとに経路を分けます。サーバー上で動く判定スクリプトでは、そのサーバーの IP しか確認できません。このページはブラウザから各サービスに直接アクセスするので、ふだん実際に使っている経路で確認できます。

「公式 API」「公式の位置判定」「転送で判定」「推定」の違いは？

結果の確かさを表し、上ほど確実です。公式 API：サービス自身の地域 API が、使えるかどうかを直接答えます。公式の位置判定：サービスのサーバーがどの国と判定したかを読み取り、公表されている対応国と照らし合わせます。転送で判定：「利用できません」のページに転送されたかどうかを見ます。推定：サービスが何も読ませないため、開けることだけを確認し、国はほかのサービスの判定を使います。

サービスによって判定される国が違うのはなぜですか？

プロキシのルールでサービスごとに別のサーバーを通っている（スプリットトンネル）か、サービスごとに使っている IP データベースが違うためです。その場合は、どの国をどのサービスが判定したかを一覧で表示します。そろえたいときは、これらのサービスを同じサーバーに通してください。

なぜタイムゾーンを見るのですか？

AI サービスは、ブラウザのタイムゾーンと IP の国を比べています。たとえばタイムゾーンが日本なのに IP がアメリカだと、プロキシを使っているように見え、追加の確認を求められることがあります。端末のタイムゾーンを IP の国に合わせると、こうなりにくくなります。

データはアップロードされますか？

確認中は送られません。ブラウザが各サービスに直接アクセスし、このサイトはページを配信するだけで、結果は見えません。1ms.dog で共有したときは、チャットアプリでプレビューを表示するために、短縮リンクとプレビュー画像が 1ms.dog に保存されます。共有した結果に IP は含まれません。スクリーンショットの前に「IP を隠す」を押せます。
