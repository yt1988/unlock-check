Частые вопросы

Где можно пользоваться Perplexity?

Почти везде, кроме: Иран · КНДР · Куба · Сирия.

Как эта страница понимает, работает ли Perplexity?

Perplexity работает через Cloudflare. На собственном домене Perplexity адрес /cdn-cgi/trace возвращает страну, из которой пришёл запрос, и другие страницы могут её прочитать. Это и есть местоположение, которое видит сам Perplexity; страница сверяет его со списком поддерживаемых стран.

Perplexity показан как недоступный, хотя мой прокси в поддерживаемой стране. Почему?

Каждый сервис определяет местоположение IP по своей базе, и они не всегда совпадают: один и тот же прокси для одного сервиса в Японии, для другого — в Гонконге. Некоторые сервисы ещё и отклоняют IP дата-центров и известные VPN. Показана та страна, которую видит сам Perplexity. Попробуйте другой сервер; домашний IP обычно проходит легче.

Зачем проверять в браузере?

Прокси-приложения (Clash, Surge, Shadowrocket и подобные) могут отправлять разные сайты по разным маршрутам. Скрипт на сервере проверяет только IP этого сервера. Эта страница заходит на каждый сервис из вашего браузера, по маршруту, которым вы на самом деле пользуетесь.

Что значат «Официальный API», «Официальная геолокация», «Тест редиректов» и «Оценка»?

Это степень надёжности результата, от самой высокой к самой низкой. Официальный API: региональный API самого сервиса отвечает, работает ли он. Официальная геолокация: серверы сервиса сообщают, какую страну видят, и она сверяется со списком поддерживаемых стран. Тест редиректов: отправил ли сервис вас на страницу «недоступно». Оценка: сервис ничего не даёт прочитать, поэтому известно только, что он открывается, а страна берётся по данным других сервисов.

Почему сервисы видят разные страны?

Правила прокси могут отправлять их через разные серверы (раздельная маршрутизация), либо сервисы пользуются разными базами IP. В таком случае страница показывает, какие сервисы видят какую страну. Чтобы данные совпадали, пустите эти сервисы через один сервер.

Зачем смотреть на часовой пояс?

ИИ-сервисы сравнивают часовой пояс браузера со страной вашего IP. Московский часовой пояс при IP в США похож на прокси и может вызвать дополнительные проверки. Помогает выставить на устройстве часовой пояс страны вашего IP.

Мои данные куда-то отправляются?

Результаты — нет. Браузер обращается к каждому сервису напрямую, и результаты остаются в вашем браузере. Во время проверки до нашего собственного сервера в Токио доходят две вещи: файл ежечасной проверки, который читается с data.1ms.dog, и запрос одноразового имени в l.1ms.dog, по которому видно, через какой DNS-резолвер идут ваши запросы. Наш DNS-сервер видит IP этого резолвера и, если резолвер его передаёт, /24 вашей сети (EDNS Client Subnet); он хранит их 2 минуты, чтобы страница могла их прочитать, затем забывает и не ведёт журналов. Страница показывает их только вам; в ссылку для обмена они не попадают. Когда вы делитесь через 1ms.dog, короткая ссылка и картинка-превью хранятся там, чтобы мессенджеры могли их показать; в общих результатах нет IP. Перед скриншотом нажмите «Скрыть IP».
