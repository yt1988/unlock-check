Источник

Как эта страница проверяет Claude?

Claude работает за Cloudflare, чей /cdn-cgi/trace на домене Claude возвращает страну соединения и позволяет любой странице её прочитать. Эта страна сверяется с опубликованным списком Claude. Это та же точка, где Claude проверяет вас.

Claude пишет «недоступен», но мой прокси в поддерживаемой стране?

Каждый сервис определяет ваш IP по своей базе, и они не всегда совпадают: один и тот же прокси для одного сервиса в Японии, для другого — в Гонконге. Некоторые сервисы также отклоняют адреса дата-центров и известных VPN. Показана страна, которую видит сам Claude.

Зачем проверять из браузера?

Прокси с правилами (Clash, Surge, Shadowrocket, sing-box…) выбирают маршрут для каждого сайта. Скрипт на сервере видит только IP сервера; эта страница опрашивает каждый сервис из вашего браузера, так что каждый запрос идёт по маршруту, который ему дают ваши правила.

Что значат «Свой API», «Свой сервер», «Редиректы» и «Вывод»?

Насколько надёжен вердикт, от сильного к слабому. Свой API: ответил региональный API сервиса. Свой сервер: сервер Cloudflare самого сервиса называет страну, в которой вас видит, сверено с его списком. Редиректы: страница посчитала, куда сервис вас отправил. Вывод: сервис прочитать нельзя; он открывается, а страна — та, что видит большинство сервисов.

Почему не все сервисы видят одну страну?

Ваши правила могут вести их через разные прокси, а каждый сервис определяет IP по своей базе. Если страны расходятся, страница показывает, какие сервисы какую видят.

Почему важен часовой пояс?

ИИ-сервисы сравнивают часовой пояс браузера со страной IP. Браузер в Europe/Moscow с американским IP — типичный признак прокси и может вызвать более строгие проверки.

Отправляется ли что-нибудь на этот сайт?

Нет. Ваш браузер обращается к каждому сервису напрямую; этот сайт отдаёт только статические файлы и не видит ваших результатов. Перед скриншотом скройте IP.
